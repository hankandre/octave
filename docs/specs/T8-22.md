## Goal

T2-05 built `launchRequest` (`packages/core/src/player/launch-request.ts`), the one function that turns a negotiated plan into what an engine plays. Its review and T2-06 left six lows on that function and one on `docs/security.md`. T8-02 is the first engine that will receive a launch request, and the original-file branch has no native re-check, so the core must refuse what it should not send. After this task:

1. The request carries the parsed URL's `href`, so the engine reads the same URL the core checked.
2. A URL with a fragment, a bracketed credential parameter name, `Token=` anywhere in it, or `MediaBrowser` in its query is refused (Product Owner decision 3).
3. Only two shapes pass: `/Videos/{id}/stream` with `Static=true`, and `/videos|audio/{id}/master.m3u8` under the server's base path.
4. Every URL passes R1 (plain ASCII authority, as written) and R2 (plain ASCII parsed host), and the gateway applies both to a server-supplied subtitle URL before it parses it.
5. A start position that is not a finite number is sent as 0.
6. When the launch request refuses a negotiated converted plan, the coordinator stops that plan's play session on the server (Product Owner decision 2).
7. `docs/security.md` says so and names the tests.

No port member, native method, event, error code, on-screen sentence or dependency is added.

## Approach

### The launch rules

`checkedUrl(value)` runs these in order on the stream URL, on the server URL (HLS), and on every track's `deliveryUrl`. Each failure throws a fresh `LaunchRefusedError`; no rule adds a detail, a code or any part of the input to it.

- **L0 (as today).** A string that parses, `http:` or `https:`, no user name or password, no query name for which `isCredentialQueryName` is true.
- **L1 (R1 as written).** `hasPlainAsciiAuthority(value)` on the string before `new URL` sees it.
- **L2 (R2).** `isPlainAsciiHost(url.hostname)` after parsing.
- **L3 (fragment).** Refused when the string holds a `#` or `url.hash` is not empty. `hls-url.ts:83` reads the raw string the same way.
- **L4 (bracketed credential name).** For each query name, split on `[` and `]`; refused when any piece is a credential name by `isCredentialQueryName`. This covers `api_key[]`, `api_key[0]`, `x[token]` and `%5Bapikey%5D`. The rule is local to `launch-request.ts`: changing `isCredentialQueryName` would move the shared HLS vectors.
- **L5 (header text; scope set by Product Owner decision 3).** Compared in lower case. Refused when the string, its href, or the href after one `decodeURIComponent` holds `token=` anywhere. Refused when the query (the text after the first `?`) of the string, of its href, or of the href after one `decodeURIComponent` holds `mediabrowser`. `mediabrowser` in the host or the path is not refused. An href `decodeURIComponent` cannot decode is refused. No recorded plan URL holds either text (Facts).

Then, on the branch:

- **Origins (as today).** HLS: the master URL and every subtitle URL share the server URL's origin. Static: every subtitle URL shares the stream URL's origin.
- **S1 (original file).** The parsed pathname matches `^(?:/[^/]+)*/Videos/[^/]+/stream$`, in the case the gateway writes, and the query holds exactly one parameter whose lower-cased name is `static`, with the value `true`. The static branch has no server URL (the request's keys are frozen), so the base path is any prefix.
- **S2 (HLS master).** The server URL holds no `?` (L3 already refuses `#`). With `basePath` the server pathname without trailing slashes, the master pathname starts with `basePath + "/"` and the rest matches `^/(videos|audio)/[^/]+/master\.m3u8$` in any case, and the matched kind in lower case equals `plan.mediaKind`. This is `hls-url.ts:85-93` without the item id, which the launch request does not carry.

What the request then carries:

- `url`, `masterUrl`, and each `deliveryUrl`: `href` of the parsed URL.
- `serverUrl`: `href` with trailing slashes removed (D1).
- `startPositionSeconds`: `Number.isFinite(plan.startPositionTicks) ? ticksToSeconds(plan.startPositionTicks) : 0` (D4). `ticksToSeconds` itself is not changed; its other callers are out of scope.

### The gateway's subtitle rule

`buildSubtitleUrl(serverUrl, path)` sees the server's string, which the launch request never does. After the existing `new URL` parse, whose failure keeps its own sentence ("Jellyfin returned an invalid external subtitle URL."), and before anything reads the parsed URL (Product Owner decision 4; no input changes its sentence):

- **G1.** With `trimmed = path.trim()`: when `trimmed` does not start with a single `/` (the test `hls-url.ts:73` uses), it must pass `hasPlainAsciiAuthority`. A `//host/…` value and a path with no leading slash are refused by this rule; no recorded `DeliveryUrl` has either form.
- **G2.** `serverUrl` passes `hasPlainAsciiAuthority`, and after parsing `isPlainAsciiHost` holds for the subtitle's host and the server's host.

A failure throws the function's existing fixed error ("Jellyfin returned an unsafe external subtitle URL. …"), so no sentence is added. The existing checks stay in their order after it.

### The coordinator's stop

In `beginAttempt`, one of the two failure paths calls `this.reporter.stopEncoding(plan)` before throwing (Product Owner decision 2):

- `gateway.sessionId()` throws: **no stop**; `throw redactTransportError(error)` as today, unchanged. The session is gone, so the stop could not be sent and would only raise a second message.
- `launchRequest(plan, sessionId)` throws: stop, then rethrow the same `LaunchRefusedError`.

`stopEncoding` queues the bounded DELETE into the reporter's drains and returns at once, so the refusal is not delayed; `flush()` and the next attempt wait for it as they do for a retry. `previousPlan` and `plan` stay unset: nothing was subscribed or launched, and the reporter's own set stops a second DELETE for the same play session.

## Risks and out of scope

- **An HTTPS server with an internationalized name can lose all playback on a host whose URL parser does not punycode.** There the gateway's normalized server URL keeps the non-ASCII host, the static URL built from it fails L1, and every launch is refused. T2-06 D6 already accepted this for conversions; item 4 extends it to the original file by its own wording. Under Node and a punycoding parser nothing changes.
- **A server whose `DeliveryUrl` has no leading slash, or is protocol-relative, loses that plan** (G1 throws, as an unsafe subtitle URL does today). No recorded answer has one.
- **L5 can refuse a harmless URL.** A parameter such as `PlayToken=`, or a query that holds `mediabrowser`, refuses that URL. No recorded URL holds either text. The whole-server case is closed: the Product Owner narrowed the `MediaBrowser` half to the query (decision 3, a scope edit of item 2), so a server named `mediabrowser.example` or served under `/mediabrowser` plays.
- **No stop is sent when the session is gone** (Facts, "A signed-out gateway cannot send the stop"; Product Owner decision 2). A signed-out client cannot authenticate any stop; the server's own session cleanup is what remains. Unverified how long Jellyfin or Jellyscale keeps an unclaimed conversion.
- **A base path with a segment named `Videos`** passes S1 as any prefix does; S1 cannot know the base path on the static branch.
- **The href depends on the host's URL implementation.** That is the point: the engine gets the serialization of the parser that checked the URL. The new tests run under Node only; the device conformance suite (`pnpm tv:e2e`) is not extended here.
- **Out of scope, to log as backlog lines by the follow-ups step:**
